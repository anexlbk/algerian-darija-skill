# Narrative register (storytelling, captions, longer written pieces)

Chat Darija and story-written Darija sound different. This file is for when Claude is asked to write something longer and structured in Darija: a story, an anecdote, a narrated caption. Patterns pulled from a set of children's stories translated into Darija, which is clean, grammatical, and consistent in how it handles narration (as opposed to the chat register in phrasebank.md, which is looser and more code-switched).

## Story openers

- كان يا ما كان — "once upon a time" (classic opener, timeless/folkloric)
- كان يا ما كان في قديم الزمان — extended version, more formal-storytelling
- واحد النهار — "one day," used both as an opener and as a scene-transition mid-story
- في قديم الزمان وسالف العصر والأوان — fuller folkloric opener, feels like "long long ago"

## Narration structure

- Third-person past narration uses plain past tense verbs, same root system as chat Darija, no special "literary" conjugation: كانت, راحت, شافت, قالت, حبت, بدات
- "كانت كاين / كان كاين" for "there was" (a person/thing existing in the story) — gendered to match the noun: كانت كاينة بنت... / كان كاين ولد...
- Descriptive stacking is common and not overwritten: "بنية صغيرة وحلوة واسمها مريم" (a small and pretty girl named Mariam) — name introduced right after description
- Dialogue is introduced directly, often with "قالت لـ" / "قال لـ" + name, then a colon and the quote, matching how it's transcribed in chat too

## Scene transitions

- واحد النهار — new event/day
- من بعد — afterwards
- وفجأة — suddenly
- حتى — until (also used to mean "so much that...")
- بصح — but (same as chat register)
- في الأخير — in the end
- وهي/وهو + present-tense verb — "while she/he was [doing]," sets a background action: "وهي تمشي، شافت..." (while she was walking, she saw...)

## Emotional/descriptive vocabulary common in narrative Darija

- فرحت / فرحان(ة) — became happy / happy
- حزينة / زعلانة — sad / upset
- تخوّفت / خافت — got scared / was afraid
- تعجبت / عجبها — was surprised / liked it
- قررت — decided
- خمّمت — thought about it, pondered

## What NOT to do in narrative Darija

- Don't slip into MSA narrative conventions (فجأة إذ بـ..., وإذا بـ..., ذات يوم بينما) — those are literary MSA calques, not how Algerian storytelling actually reads even in written form.
- Don't drop the -ch negation or ديال/تاع possession just because it's "written" register — the grammar stays Darija, only the vocabulary gets slightly less slang-heavy and French insertion gets lighter.
- Keep sentences relatively short and paratactic (linked with و، بصح، حتى) rather than building complex subordinate clauses the way MSA prose does.

Source note: this register was extracted from AI-translated children's stories, so treat it as a solid grammar/structure reference, not as a source of slang or idiom — cross-check any vocabulary choice against phrasebank.md or loanwords.md if precision matters.
